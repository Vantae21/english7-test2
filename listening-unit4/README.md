# Listening · Unit 4 – Music and Arts (Tiếng Anh 7 Global Success)

## Cách đưa lên GitHub (làm 1 lần)
1. Vào github.com → **New repository** → đặt tên (ví dụ `listening-unit4`) → chọn **Public** → **Create repository**.
2. Bấm **uploading an existing file** → kéo thả TOÀN BỘ nội dung thư mục này (index.html, config.js, thư mục `audio`, thư mục `img`) vào → **Commit changes**.
   (Nếu kéo thư mục không được, giải nén ra rồi kéo cả hai thư mục `audio` và `img` cùng các file lẻ.)
3. Vào **Settings → Pages** → mục *Build and deployment*: Source = **Deploy from a branch**, Branch = **main** / **(root)** → **Save**.
4. Đợi 1–2 phút, link làm bài sẽ có dạng: `https://TEN-TAI-KHOAN.github.io/listening-unit4/`

## Cài email nhận bài (làm 1 lần – bắt buộc để bài gửi thẳng về mail cô)
1. Vào https://web3forms.com → nhập **email cá nhân của cô** → **Create Access Key**.
2. Mã (dạng `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`) được gửi về email đó.
3. Trên GitHub mở file `config.js` → bấm biểu tượng cây bút → thay `PASTE_ACCESS_KEY_HERE` bằng mã vừa nhận (giữ nguyên dấu nháy kép) → **Commit changes**.
4. Làm thử một bài bằng link Pages để kiểm tra mail về hộp thư (xem cả mục Spam lần đầu).

Học sinh nhập họ tên + lớp → làm bài → bấm **Nộp bài**: bài được gửi tự động (tự thử lại 3 lần; nếu mất mạng sẽ hiện nút “Gửi lại”, và bài được lưu trong trình duyệt để gửi lại sau).

Email gồm: tên, lớp, điểm, điểm từng Part, thời gian làm và chi tiết từng câu (con chọn gì / đáp án đúng).
Lưu ý: gói miễn phí của Web3Forms có giới hạn số bài mỗi tháng, cô xem mức hiện tại trên web3forms.com.
